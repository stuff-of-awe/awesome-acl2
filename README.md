# Awesome ACL2 and ACL2s

ACL2 combines a functional programming language, formal logic and theorem proving; ACL2s adds a teaching-oriented workflow. This collection covers both without treating them as different proof kernels.

**Status:** starter collection, initial review 2026-11-15. **Curator:** unassigned — contributions welcome. Entries are original short annotations of external sources, not endorsements or copies of their content. No tool was installed or executed for this initial list.

## Start here

- [ACL2 project](https://www.cs.utexas.edu/~moore/acl2/) — Find releases, an overview of the logic, and the authoritative starting points.
- [ACL2 tutorial](https://acl2.org/doc/index-seo.php?xkey=ACL2____ACL2-TUTORIAL) — Follow the authors' suggested route rather than beginning with the entire manual.
- [ACL2s project](https://acl2s.ccs.neu.edu/) — Explore the ACL2 Sedan beginner-focused interface and pedagogy.

## References and implementations

- [ACL2 source and community books](https://github.com/acl2/acl2) — Inspect the prover and its separately contributed book libraries in one repository.
- [ACL2+Books manual](https://acl2.org/doc/index-seo.php?xkey=ACL2____TOP) — Look up events, hints, proof rules and book interfaces.

## Examples and community routes

- [Community Books](https://github.com/acl2/acl2/tree/master/books) — Find examples spanning arithmetic, hardware and software reasoning.
- [ACL2 GitHub discussions and issues](https://github.com/acl2/acl2/issues) — Trace practical problems to maintainers and source changes.

## First exercise (not yet execution-tested here)

Try a simple recursive function and theorem from the ACL2 tutorial; inspect proof output and note the version and books loaded.
